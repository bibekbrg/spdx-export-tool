Why this tool, and not just AI?

Never guessesUnknown values become NOASSERTION; missing required data is an error. AI can invent a license or checksum.
Same output every timeDeterministic IDs and ordering, so results can be audited and compared between releases.
Officially validatedEvery file is checked against the official SPDX 2.3 JSON schema before it is saved.
Traceable, offline, fastEvery value traces back to the scan. Runs locally; 1,000 files in well under a second.
